# Optional legacy world-motion preset

Not selected by default. Read the installed video-production-workflow/references/legacy-world-motion.md only when the user chooses illustrated/cartoon/world-motion choreography. The installer stores the portable two-tree legacy archive at `<CODEX_HOME>/video-presets/video-production-20261117/`; the same source archive is under this repo's video-production/presets/legacy-world-motion/. Three.js, characters, a fixed palette and actor/target audits are not universal requirements.
