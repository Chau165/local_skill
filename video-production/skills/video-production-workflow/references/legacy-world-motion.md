# Optional legacy world-motion preset

Activate only when the user explicitly selects illustrated/cartoon/world-motion production. Otherwise do not load the archived instructions or run world-motion-audit.mjs.

The installer preserves the full original two-tree layout under `<CODEX_HOME>/video-presets/video-production-20261117/`, where CODEX_HOME defaults to the user's `.codex` directory. Inside are `codex/skills/` and `agents/skills/`. The same files are archived in this repository at `video-production/presets/legacy-world-motion/`; portable file hashes and upstream provenance are in `video-production/manifest.json`.

Select the relevant archived animation blueprints/adapters, creative guidance, media pipeline and CLI/scripts/world-motion-audit.mjs. Useful techniques include independent layers, action/reaction, subject/target state changes, camera continuity, inspected assets and finite seek-safe motion. Three.js is optional; a 2D illustrated world does not need a 3D engine.

Current runtime and user instructions prevail over old recipes. Preserve complete captions and original voice. Legacy bans on cards or primitive graphics apply only if the selected style calls for them. A visual preset does not authorize AI narration, private uploads or changed factual claims. Legacy recipes are preserved, not all render-tested on this snapshot.
