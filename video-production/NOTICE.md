# Attribution and scope

This add-on archives user-requested video Agent Skills. It is not an installation of the complete HyperFrames, Remotion or OpenDesign framework/app. Upstream commit identities and local patches are recorded in manifest.json.

- HyperFrames: https://github.com/heygen-com/hyperframes (Apache-2.0 upstream; retain applicable source notices).
- OpenDesign: https://github.com/nexu-io/open-design. Included functional helpers retain their original notices. gsap-timeline is curated from GreenSock's official GSAP skills and retains its own MIT notice.
- Remotion Agent Skills: https://github.com/remotion-dev/skills. Included notices remain in their original directories and licenses/ when provided upstream. Framework licensing is a separate matter; no Remotion framework runtime is bundled here.
- Local source-fidelity guidance and compatibility wrappers were produced for this user. No blanket license is asserted over third-party content; original component licenses govern their respective files.

No personal Codex config.toml, global AGENTS.md, auth files, API keys, footage, voice recordings, transcripts, model weights, caches or runtime executables are part of this add-on. workspace/AGENTS.md is a video-only template, not global configuration. Legacy SKILL.md files under presets/ are archival and must not be installed as a second active skill tree.
