# Unity MCP Tool Reference

## Read First

- `mcpforunity://editor/state`
- `mcpforunity://scene/gameobject-api`
- `mcpforunity://custom-tools`

## Common Tool Usage

- Use scene tools for scene loading, validation, and hierarchy inspection
- Use GameObject and component tools for object-level edits
- Use console tools after any script or scene mutation
- Use camera screenshot tools for visual verification
- Use batch operations for repeated object actions

## Verification Targets

- compile state
- console errors
- missing references
- object active state
- renderer visibility
- transform alignment
